# Memory

Durable things worth every AI knowing that are not already in `USER.md`: facts about my
situation, decisions I have made, lessons I do not want to relearn. At most 20 entries or
1,500 words. When it is full, the next write asks for a consolidation instead of pushing
something out. Raw notes live in `memory/`; this file is what survived.

Each entry: a date it became true (`since`), a date it stopped being true (`until`) if it
has, a tag ([stated] / [observed] / [inferred]), and the note in one or two lines.

- since 2026-10-11 [stated] I run my own bookkeeping practice from home; most clients are tradies.
