# The tidy, by hand

`scripts/tidy.py` does this; an agent that cannot run scripts does the same steps, in the
order 4, 1, 2, 3, 5, 6, 7, 8, 9: proposals come before the archive so nothing expires unseen.
The tidy never changes `USER.md`, `SOUL.md`, `MEMORY.md`, `FLEET.md`, `HEARTBEAT.md`,
`LEARN.md`, `skills/` or `try/` except step 4.

1. **Archive.** Move every `memory/*.md` note whose filename date is more than 30 days
   old into `memory/archive/`. Never edit a note beyond appending a status line (`applied:`, `queued:`).
2. **ACTIVITY.md.** One line per note, newest first, at most 30: the date, the app, and
   the first bullet under `## Did` (the five note headings are `## Did`, `## Decided`,
   `## Remember`, `## Proposes`, `## Flags`, exactly). A note with `issue` or `error` in a bullet under its `## Flags` heading gets that
   word at the end of its line.
3. **SKILLS.md.** One line per folder under `skills/`: the `name` and `description` from
   its `SKILL.md`.
4. **Proposals.** Runs before the archive step so nothing expires unseen. Any `## Proposes` block in any note, including `memory/archive/`, whose line starts with `approved` is
   applied to the named curated file (append the line with the date and tag; mark any
   line it supersedes). Mark the note `applied: <date>`. Count the rest as pending.
5. **Privacy check.** Scan every file except `vault/` for things that should never be in
   a rucksack: anything shaped like a card number, a tax file number, a bank account
   and BSB, a phone number, an email address, or a date of birth outside `USER.md`.
   Write what was found (file, line number, the kind, never the value) to `CHECK.md`.
   An empty check is a one-line file saying so, with the date.
6. **Budgets.** `START.md` under 200 lines; `MEMORY.md` under 20 entries and 1,500
   words; `USER.md` under 120 lines. Over budget is reported in `CHECK.md`, never cut.
7. **START.md.** Rebuild it entirely, in this order, from the files it points to:
   a title line with the person's name and the date generated, then the two lines under it
   ("Read this first..." and "You are my AI...");
   "Me in six lines" from `USER.md` In short;
   "My boundary" from `USER.md` My boundary;
   "House rules", the five fixed lines exactly as `scripts/tidy.py` writes them
   (`HOUSE_RULES`);
   "How to be with me" from the first seven bullet lines of `SOUL.md`;
   "How I like to learn" from `LEARN.md` How I like to learn, then the fixed teaching line
   (`TEACH_LINE`);
   "Working on now" from `LEARN.md` Working on now plus the title line of each file in
   `projects/`;
   "Routines" from `HEARTBEAT.md` (the count and the names, or "none");
   "Learning" from the header line of `LEARN.md`, with "look-back due now" if the due date
   has passed, the number of pending proposals, and the pointer to `skills/teach/SKILL.md`;
   "Recent" from the first five lines of `ACTIVITY.md`;
   "Map": one line per file and folder, what it is for;
   a last line: "Generated by the tidy. Do not edit; edit the files above."
   The dashboard, `view.html`, is only rebuilt by the script; an agent that cannot run
   scripts says it is out of date.
8. **rucksack.yaml.** Set `last_tidy` to today.
9. **Pilot.** If `rucksack.yaml` says `pilot: true` and an unqueued note has `feedback`
   under `## Flags`, copy that note's Did, Decided and Flags lines into
   `feedback/<date>-<app>.md` and append `queued: <date>` to the note. The file is
   queued, not sent, on every tier: the person reads it and sends it to `pilot_contact`
   (the AI offers a ready email). Nothing under the boundary goes in; if in doubt,
   leave the line out.
